- **Fixed: a deleted player can no longer write anything from a browser that is still signed in (#822).** The session is cached in a signed cookie for up to five minutes, so after an organizer deleted a contestant, that contestant's open browser still passed as signed in and could, for example, create a team tied to an account that no longer existed. Every player write (team create, join, leave, rename, remove, transfer, disband, new join code and solo; flag and quiz submits; hint buys; username and password; linking GitHub) now checks that the account still exists and answers 401 when it does not. Pages can still render from the cache until it expires. A Redis error on that check refuses the write.
