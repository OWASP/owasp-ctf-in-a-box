- **Changed: v2.0 players are kit accounts, and GitHub is needed only for Secure Development (#731, #744).** Players create an account on the box with a username and password; GitHub sign-in appears when you add its keys and leave its switch on in `/admin`. Every record is keyed by a player id, and admins are claimed with a one-time code. **Breaking:** v1 accounts and progress do not carry over. To upgrade, export the v1 event archive and keep it, remove `ADMIN_LOGINS` from `.env`, generate a claim code (`ctf-setup.sh admin-code`, or `deploy.sh --new-admin-code` on Fly and AWS), deploy v2, claim `/admin`, and run the master reset before players sign up. The steps are in `docs/hosting.md` under "Upgrading from v1"; the decision is ADR 74.
