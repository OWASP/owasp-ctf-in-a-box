- **Added: admin account tools — reset codes, rename, unlink, delete with a re-link block, delete all accounts (#740).** In the Support tab an organizer can issue a single-use, 15-minute password reset code (the player redeems it at `/reset` and picks a new password; every session is signed out), rename a player, and unlink an unscored GitHub link. Deleting a contestant now removes the account itself and blocks their GitHub login from linking again until the next master reset, and refuses an organizer. The Event tab's danger zone adds Delete all accounts (type `delete all accounts`), which deletes every account including yours and every admin grant: rotate the claim code first (`ctf-setup.sh admin-code`, or `deploy.sh --new-admin-code`), then claim `/admin` again.
