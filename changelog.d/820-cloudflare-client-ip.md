- **Fixed: sign-up and sign-in rate limits behind Cloudflare key on each player's public address, not on Cloudflare's edge (#820).** With the domain proxied by Cloudflare, every player reached the box from a Cloudflare edge address and shared one sign-up and one sign-in budget. Set `CLOUDFLARE_ORIGIN_SECRET` (`.env`, `.env.fly`; on AWS `behind_cloudflare = true` and the value in SSM) and add a Cloudflare Transform Rule that sets the `x-ctf-origin-secret` request header to the same value (`docs/hosting.md`, "Cloudflare in front of the box"). The app then keys those limits on `CF-Connecting-IP`, only for requests that carry the secret from a Cloudflare edge address, so a client reaching the origin directly, or through another account's Cloudflare Worker, cannot pick its own budget. A value shorter than 32 characters or with whitespace stops the app at startup. The per-address budgets are raised for a room of about 650 people sharing one venue NAT address: account creation from 300 to 1000, and sign-in from 600 to 2000, per 10 minutes.
