- **Added: Google and Discord sign-in, and per-provider switches in /admin (#739).** Set `GOOGLE_CLIENT_ID`/`GOOGLE_CLIENT_SECRET` or `DISCORD_CLIENT_ID`/`DISCORD_CLIENT_SECRET` (both keys, then restart the app) and the provider appears on `/sign-in` and as a switch in the Event tab's Sign-in section; turning one off stops new sign-ins through it but does not sign out existing sessions. No provider email, name or avatar is stored for Google or Discord. The GitHub keys are now needed only with Secure Development: an event without it can run on username and password, Google or Discord alone. Fly takes the new keys as optional in `.env.fly`; AWS takes `google_client_id`/`discord_client_id` with the secrets in SSM.
