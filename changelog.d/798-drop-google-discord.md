- **Changed: GitHub is the one OAuth sign-in provider (#798).** Players sign in with a username and password, or with GitHub when its keys are set and its `/admin` switch is on. A box that ran a pre-release v2 build with Google or Discord keys can delete them from `.env` (`.env.fly` on Fly, the Google and Discord client id variables in `terraform.tfvars` on AWS); nothing reads them. A player who signed in only with Google or Discord needs an organizer to set a username for them in Support, if they have none, and give them a reset code.
